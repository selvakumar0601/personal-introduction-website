# 🌐 Personal Introduction Website

## 📌 Project Description

This project is a simple and responsive personal introduction website created using HTML5 and CSS3.

The website showcases my personal information, profile image, introduction, skills, hobbies, and contact details in a clean and modern layout.

## 🎯 Objective

The main objective of this project is to practice basic HTML elements and CSS styling concepts, including:

- HTML5 Structure
- CSS Selectors
- Spacing and Layout
- Colors and Typography
- Responsive Design
- Profile Image Styling

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- 👤 Personal Profile Section
- 📝 About Me Section
- 💻 Skills Section
- 🎮 Hobbies Section
- 📧 Contact Information
- 🔗 GitHub Profile Link
- 📱 Responsive Design
- 🎨 Modern UI Design
- ✨ Hover Effects

## 📂 Project Structure

```text
personal-introduction-website/
│
├── index.html

```

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/selvakumar0601/personal-introduction-website.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.
